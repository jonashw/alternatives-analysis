Situation: In a real AA, a criterion named for a feature (a screen reader reading every row) hid the reason it mattered (software being able to read the rows: the engine and tests). Jon renamed it so the name carried the reason.
Jon said: "a criterion's name should carry why it matters, not only the feature." and "Worth a line in the spec's guidance on writing criteria."
Observed: The spec had no guidance on wording criterion names. Added "Name the reason, not just the feature" to all three variants, with a neutral example.
Inferred (my reading): the owner ranks the words on the button, so a feature-shaped name can quietly mis-weight the need behind it.
